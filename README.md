## Project Description

A useless table that starts vibrating when a person comes near it to write.

The table uses IR sensors to detect the person and servo motors to create unnecessary vibrations. An LCD also displays funny messages during the process.

---

## The Problem (that doesn't exist)

People can write peacefully on normal tables.

Our project solves this completely unnecessary problem by making the table vibrate whenever someone tries to write on it. 

---

## The Solution (that nobody asked for)

We made a table that detects when a person comes near using IR sensors.

The Arduino then activates three servo motors, which create vibrations on the table. The LCD displays funny messages while the table makes writing unnecessarily difficult. 

---

### For Software:

### For Hardware:

- Jumper Wires

---

# Implementation

## For Software:

### Installation

1. Install Arduino IDE.
2. Connect the Arduino Uno to the computer.
3. Install the Servo and LiquidCrystal_I2C libraries.
4. Open the project code in Arduino IDE.
5. Select Arduino Uno and the correct COM port.
6. Upload the code to the Arduino.

### Run

1. Power the Arduino and the circuit.
2. Keep the table in a stable position.
3. Place a book or object on the table.
4. When a person comes near the table, the IR sensors detect the person.
5. The servo motors start moving and create vibrations.
6. The LCD displays funny messages.
7. When the person moves away, the table returns to its normal state.
